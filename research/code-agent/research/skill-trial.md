## 本次发现的 Skill 改进点

1. 大输出必须按“执行捕获 → 工具格式化 → 通用序列化 → artifact → Provider 回灌”逐层核对。后层保存内容不能补回前层已丢弃的字节。
2. compact 不能只写成一种摘要操作；需要区分完整摘要压缩、microcompact 和 Provider 处理，并核对持久化与冷恢复语义。
3. Memory 的去重、冲突和过期策略需要区分代码强制与提示词约束，不能把模型应遵守的规则写成系统 invariant。
4. 试跑状态要分别报告静态源码、测试支持和真实运行，防止“已实测”掩盖验证层级。

以上四项已反写到问题库、证据深度标准、报告模板和试用验收规则。
